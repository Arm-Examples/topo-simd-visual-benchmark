About This Demo

This benchmark demonstrates the real performance impact of SIMD (Single Instruction, Multiple Data) optimizations on Arm processors. All three backends run identical C++ code performing box blur convolution on images, but compiled with different architecture flags:

  • Scalar: No SIMD, processes one value at a time
  • NEON: 128-bit SIMD, processes 4 floats simultaneously
    • {% if sve_enabled %}
  • SVE: Scalable vectors (128-2048 bits), processes even more data in parallel
    • {% endif %}

The performance differences you see are genuine hardware acceleration, not synthetic effects. Default settings (128x128, radius 10) are optimized to show clear SIMD speedups.

Experiment tip: Performance characteristics vary dramatically with image size and blur radius! Try different combinations to discover when SIMD shines (small images, large kernels) versus when it struggles (certain middle-ground sizes show surprising scalar wins). Real-world optimization requires measurement!
