About This Demo

This benchmark demonstrates the real performance impact of SIMD (Single Instruction, Multiple Data) optimizations on Arm processors. All three backends run identical C++ code performing box blur convolution on images, but compiled with different architecture flags:

  • Scalar: No SIMD, processes one value at a time
  • NEON: 128-bit SIMD, processes 4 floats simultaneously
    • {% if sve_enabled %}
  • SVE: Scalable vectors (128-2048 bits), processes even more data in parallel
    • {% endif %}

The performance differences you see are genuine hardware acceleration, not synthetic effects. Default settings (512x512, blur radius 10) are optimized to show clear SIMD speedups.
